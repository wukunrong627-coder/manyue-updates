# 漫阅 Android 更新

<!-- manyue-personal-update-distribution-v1 -->

此仓库只用于漫阅的个人更新分发。仓库和下载文件公开可访问，不提供密码验证。

## 在漫阅中填写

打开 **设置 → 关于漫阅 → 应用更新**，将以下完整 HTTPS 地址设为更新地址：

```text
https://github.com/wukunrong627-coder/manyue-updates/releases/latest/download/latest.json
```

当前发布版本为 **0.6.0（versionCode 60）**。已安装 0.6.0 时提示已是最新版本属于正常现象。
Android 7.0 或更新版本可用。首次从 0.5.0 升级，需要先手动覆盖安装 0.6.0；不要先卸载。
